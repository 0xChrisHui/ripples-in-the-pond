# 首页第36特殊音乐圆圈（2026-10-08）

用户定案（对话确认，无开关）：

1. 白色；播放态不另做提示。
2. 常态正圆（边缘波/激励/果冻对 #36 置 0）；日食不改。
3. 半径 ×2；碰撞、命中层、日食随 node.radius 同步变大；碰撞维持纯 2D 互挤。
4. 对 #36 关闭 cluster 锚点、link 拉力、随机游走与暗流；涟漪推、拖拽、颤动、hover 放大保留。
5. 主动行为：屏幕空间漂流（直线/弧/S/蜿蜒/钩形，多种速度曲线，停顿，转向分布，探索偏好）、
   主动换层（跳层数/方向/时长/停留随机，透视随层变化，绘制顺序动态调整）、
   隐现（完全/半隐、渐变时长、隐藏时长、换位重现、配合下沉；隐藏不可点）。
6. 性格层：活跃度随机漂移，调制上述全部区间。
7. 整球留在可视区内，避开顶栏与左侧分组导航。
8. 播放、悬停、拖拽时暂停隐退；播放时冻结主动漂流/换层以稳住日食。

实现：`src/components/pond-gl-test3/special36/`，由 `sphere-frame.writeFrame` 每帧驱动。
