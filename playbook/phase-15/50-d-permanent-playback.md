# P15-D — 永久 NFT 的高速播放与断站复现

> **目标**：网站在线时快速开始播放；本站或高速镜像关闭后，NFT 仍可从链上、Arweave 和永久 Decoder 复现。
> **前置 Gate**：用户明确授权同步 `docs/ARCHITECTURE.md`，并批准高速镜像服务与成本边界。

---

## 1. 两层真相

```text
永久层（不可替代）
tokenURI → Arweave metadata → recipe/events/base/sounds/clips → 永久 Decoder

高速层（可删除、可重建）
Arweave txid/content hash → CDN/object storage 镜像 → 当前站内播放器
```

- CDN URL 不反向覆盖永久 `ar://` 引用。
- 镜像丢失时可从 Arweave 重新构建，不需要重铸 NFT。
- 本站关闭模拟必须屏蔽 app 域名和高速镜像域名，只允许链上、Arweave 与永久 Decoder。

---

## 2. 为什么不常态使用后端音频代理

“浏览器 → Next.js API → Arweave”会增加一次往返，把流量和超时集中到函数运行时，并可能破坏 Range/流式缓存。P15 默认采用提前镜像的静态对象；后端只负责受控回填、索引和完整性验证，不在每次播放时搬运整段音频。

---

## 3. 统一资源解析器

输入是永久 `ar://txid` 与可选内容哈希，候选顺序为：

1. 已验证的同字节高速镜像；
2. `arweave.net`；
3. `ario.permagate.io`。

合同要求：

- 每个候选有超时、AbortSignal、Range/Content-Type/长度检查和有界重试。
- 镜像创建时校验 SHA-256；客户端不得把同 txid 的不同字节静默当成功。
- 失败信息区分 DNS、超时、HTTP、解码和格式问题，便于定位而不泄露内部凭证。
- Score 与 P14 共用解析能力，但各自保留独立播放状态机。

---

## 4. 现有 ScoreNFT 路径

- 现状会在 ready 前获取 events、sounds map、底曲和全部使用音效，点击后集中 `decodeAudioData`。
- 第一轮优先验证“永久组成资源的高速镜像 + 更早/分批解码”能否达到预算。
- 只有组成资源优化仍不能满足首播预算，才制作单个 master audio 技术样板，并比较：生成成本、P9 时间线同步、历史 NFT 索引和永久性。
- 历史 metadata 不可改；任何 master 都不能伪装成原 tokenURI 内已有字段。
- 播放已经开始后的断音若发生在全部资源已解码之后，转查主线程长任务、GL负载、GC和 AudioContext 调度。

---

## 5. P14 配方 NFT 路径

- 36 个固定碎片只需在高速层各镜像一次，不为每个钱包生成重复四分钟 MP3。
- 前端读取永久 recipe，先取得最前面的可播放窗口，再滚动预取后续唯一碎片。
- 预取窗口、并发数和移动内存上限由真实设备 Gate 决定；不得写死未经测量的全量预解码。
- 重复字符复用同一已解码 AudioBuffer；播放顺序仍按36位 recipe，不去重时间线。
- 永久 Decoder 不依赖高速镜像，直接读取 metadata 中的 `ar://` 地址或冻结清单。

---

## 6. 播放状态合同

- 用户点击后立即进入明确的 preparing/playing/error 状态，不用静默按钮。
- AudioContext 只在用户手势后创建或恢复。
- 暂停、续播、seek、结束和重播以同一音频时钟为准；P9/视觉只跟随该时钟。
- 当前窗口之后的资源失败时提前提示和重试，不等播放到断点才突然停止。
- 离开路由后取消下载、停止音源并释放路由级会话。

---

## 7. 故障矩阵

| 故障 | 在线站内播放器 | 永久路径 |
|---|---|---|
| 高速镜像单对象缺失 | 回退 Arweave并异步修复镜像 | 不受影响 |
| Arweave 主网关失败 | 镜像或备用网关继续 | 用备用网关打开同一 txid |
| 两个网关失败 | 已缓存/镜像可播放并明确永久层暂不可用 | 报可恢复错误，不声称绝对在线 |
| 本站域名关闭 | 不适用 | tokenURI + 永久 Decoder 完整复现 |
| 单碎片损坏 | 拒绝错误字节并切候选 | 依据永久 hash 报错 |
| WebGL 降级 | 音频继续，视觉进入 fallback | Decoder 保留基本播放 |

---

## 8. 完成标准

- Score 与 P14（若已上线）的热/冷首声达到冻结预算，失败路径有真实证据。
- 高速镜像关闭后自动回退 Arweave；本站与镜像均屏蔽时永久 Decoder 仍能播放。
- 现有 Token #1 不修改 metadata 即获得站内加速，永久凭证仍显示原始来源。
- 播放中掉帧与首播等待分别有 trace，优化结论不混淆。
- 资源解析、哈希、防重、取消和路由清理测试通过；完整 `scripts/verify.sh` 全绿。

---

## 9. 必停条件

- 需要购买或接入新的 CDN/对象存储，或改变免费额度承诺。
- 需要修改未来 NFT metadata 永久格式、Decoder 或 P14 已冻结数据合同。
- master audio 样板将引入新编码工具、长期服务器计算或新的永久上传成本。
