# Phase 9 v2 — 共享状态与连续演奏大优化

> **来源**：2026-08-26 用户完成第一轮 45 效审阅，并拍板五项基础方向。
> **权威性**：本文件接管 P9 Track B 的下一轮施工；`00-overview.md` 保留 Track A 基线、红线与历史映射。
> **目标**：把 v1 的“每键独立候选”改造成可叠加、可调、可连续演奏的共享池塘状态系统，再完成逐键重做与第二轮集中验收。

---

## 0. 已拍板结论

1. 同一家族共享一套状态参数。不同按键修改不同参数轴，效果同时存在，不覆盖、不排队。
2. 月光采用严格白名单：默认任何效果都不能改变两种月光强度；未来需要时再单独授权。
3. 删除全按键通用圆形水波回声。只有明确的水面效果可以生成波浪。
4. K 的五组微光配色按连续点击依次切换，平滑过渡，保持一个乐句后缓慢回到基础色。
5. Y/Z 合并：Y 在两种明显形变间受控变化并支持连续演进；Z 留空。
6. Shift+A/C/H/K 进入准备删除名单，不投入重做；Shift+S 直接删除。
7. Shift+J/L/N/R 先按本文件冻结的新方向实现，再由用户目验。

## 2. v1 根因与 v2 替换目标

| v1 根因 | 用户看到的问题 | v2 目标 |
|---|---|---|
| 每个 lane 只输出能量最大的 `dominant` voice | 同类效果互相覆盖 | 输出家族共享状态，各参数轴独立混合 |
| 每个 lane 默认 `moon > 0` | ABC 等无关效果也让月光变亮 | `moonWrite=false` 为默认，当前白名单为空 |
| 每个 voice 都补一个日食中心 drop | 每按一键就出现同款圆形涟漪 | 删除通用 drop，按效果显式声明水面行为 |
| voice 超限会删旧 voice，全屏冷却会拒绝新请求 | 某效果霸占、其他效果等待或消失 | 超限合并进共享状态；全屏请求交叉渐变，不排队 |
| 大量幅度和时序写死 | 用户无法快速调美 | 家族参数 + 当前 FX 参数两层控制台 |

## 3. 共享状态模型

### 3.1 数据流

```text
统一键盘事件
  → 独立 Modifier Voice（包络、强度、随机种子、参数写入）
  → 家族 Mixer（同帧混合、封顶、冲突处理）
  → Eclipse / Motes / Petals / Water / Scene 共享状态
  → 现有真实对象与 shader 消费
```

禁止消费者再读取“本家族最强的一个 mode”作为唯一结果。

### 3.2 五个家族的共享参数轴

| 家族 | 共享参数轴 |
|---|---|
| 日食 | 白环半径/亮度/厚度、光晕半径/亮度/色相、黑核半径/偏心/纹理、局部闪耀 |
| 微光 | 亮度、可见度、五色 palette、色彩混合、运动速度/方向/曲率/尺度、异步相位、汇入状态 |
| 花瓣 | 可见数量、生命周期、透明度、颜色、速度/方向/流场、边界约束、拉丝/断裂/转化状态 |
| 水面 | 波前、圆弧角、方向、速度、焦散亮暗/分裂、静止程度、折射压力；月光独立且默认只读 |
| 场景 | 共享暗流、边缘压力、折射边界、全屏遮罩、全局明暗；不能自动写月光 |

### 3.3 混合规则

- 连续标量采用加法或乘法混合后封顶，不允许最后按键直接覆盖。
- 颜色采用 palette 间插值；切换时间可调，不能瞬间跳色。
- 方向向量按 voice 权重相加后归一化；每个对象再叠加自己的种子偏差。
- 位移、尺度和亮度的随机结果必须来自可调区间，并用稳定种子保持帧间连续，禁止每帧重抽造成跳跃。
- 熄灭、汇入、湮灭等离散行为使用对象级 mask；不能把整个家族作为一个开关瞬间消失。
- 同键连击增强当前 modifier 并延长包络；异键同时保留各自参数写入。
- 超出 voice 预算时，把同参数写入合并进 accumulator，不排队、不删除整项可见效果。
- 最长余韵结束后所有 modifier 归零，恢复 P9 tuning 与水塘基础值。

### 3.4 全屏效果

- 同时只保留一个重型全屏合成层，但局部/环境效果始终并行，不受全屏冷却阻塞。
- 冷却期内的新全屏键不等待：当前全屏层向新目标交叉渐变或受限混合。
- 全屏亮度、遮罩与折射分别混合；禁止第二层贴图直接叠屏。
- 全屏效果不得隐式增强月光。

## 4. 白名单耦合

### 4.1 月光

- registry 默认 `moonWrite: false`，moon contribution 默认严格为 `0`。
- 本轮月光写入白名单为空；Shift+H 在准备删除名单中，不为它保留特权。
- Shift+O 可以用场景遮罩让画面变暗，但不得提高或直接改写两种月光强度。
- V 只操作现有焦散色块，月光输入保持不变。
- 调试 HUD 必须显示当前 effect 是否获准写月光。

### 4.2 水波

- 删除“所有候选 0.28 秒后补一个日食中心 drop”的规则。
- 可以产生真实波浪的白名单：T 方向圆弧浪、U 水滴涟漪、Shift+F 安静波。
- Shift+N 只产生边缘压力/折射前线，不生成多个圆形 drop。
- V/W/X/Shift+G 只改现有焦散，不额外制造水滴。
- 其他效果如需反馈，必须使用其家族对象、白环、焦散或场状态，不能借圆形水波兜底。

## 5. `/test3` 两层参数控制台

### 5.1 家族共享参数

所有区间必须有合理默认、保存、重置；存入独立 P9 tuning key。

| 家族 | 必须可调 |
|---|---|

| 微光 | 攻击/释放、亮度上限、palette 过渡/保持/回落、运动/方向/尺度/亮度随机区间、异步程度 |

| 水面 | 波前强度/速度/宽度、圆弧比例、焦散增益、分裂距离、效果时长 |

### 5.2 当前 FX 参数

- HUD 选中最近按键，面板只显示该 FX 的专属参数。

- 艺术参数可以调；数组容量、shader 分辨率等安全/性能常量不进入普通调参面板。
- 每个专属参数都必须在效果状态表的“可调项”列出现。

## 8. 施工 Track

### V0：冻结 v1 与参数基线

1. 保存当前 45 效映射、用户反馈和 v1 录像。
2. 为准备删除/直接删除/留空项建立 registry 状态，不立刻删 v1 代码。
3. 记录当前 P9 tuning、月光 uniform、水面 drop 数和同 lane 覆盖行为。

### V1：共享 Mixer 地基

1. 用 Modifier Voice + 家族共享状态替换 `dominant per lane`。
2. 建立标量、颜色、方向、对象 mask 四类混合器。
3. 同键合并增强；异键并行；超限写入 accumulator，不排队。
4. 全屏请求改为交叉渐变，局部/环境 modifier 始终并行。
5. 完成最长余韵归零与 reduced-motion 缩放。

**V1 验收组合**：L+K、I+K+L、J+K、N+P、T+V、Shift+O+K+N。

### V2：耦合清理与参数控制台

1. 所有 moon 默认归零并加入可观察白名单标记。
2. 删除通用日食中心 drop，建立水波白名单。
3. 新建两层 P9 参数控制台，支持保存、重置和当前 FX 切换。
4. 参数元数据、runtime 范围与 UI 单一来源。

### V3：按家族批量重做

1. 日食：A–H、Y；先解决连续性、明显度和黑核区域纹理。
2. 微光：I–M、Shift+B；共享亮度、palette、运动和对象状态。
3. 花瓣：N–S、Shift+D/E/M；全部基于真实花瓣和对象级生命周期。
4. 水面/焦散：T–X、Shift+F/G/L/N；波浪、焦散、折射各自有来源。
