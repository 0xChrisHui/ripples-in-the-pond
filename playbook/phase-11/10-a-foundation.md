## A1｜P11 设计令牌

### 设计方向

视觉名为 **夜塘唱片册 / Night Pond Editorial**：

- 首页保留纯黑夜塘、蓝色涟漪与克制金色；
- 内页使用墨黑蓝纸面、暖白正文、雾蓝技术文字；
- 成功、进行中、失败只能通过语义色补充，不反客为主；
- 边框像唱片套页的压痕，阴影只用于分层，不做发光卡片海洋。

### 📦 范围

- `src/styles/p11-tokens.css`（新建）
- `app/globals.css`（只负责引入和最小全局重置）

### 必须包含

- 页面与纸面：`--p11-ink`、`--p11-paper`、`--p11-paper-raised`
- 文字：`--p11-text`、`--p11-muted`、`--p11-faint`
- 线条与强调：`--p11-line`、`--p11-blue`、`--p11-gold`
- 状态：`--p11-success`、`--p11-warning`、`--p11-danger`
- 统一圆角、描边、页面边距、内容宽度、底部安全区
- 明确的 `prefers-reduced-motion` 基础规则

### 禁止

- 不新增 CSS 框架或字体依赖。
- 不把旧页面一次性全部改成新变量。
- 不使用无语义的 `--gray-1` 一类编号堆积。

### 验收

- 令牌命名可从用途判断含义。
- 375 px 不出现固定桌面边距。
- 对比度抽查：正文 ≥ 4.5:1，大字与控件 ≥ 3:1。
- `bash scripts/verify.sh` 通过。

## A2｜字体与排版契约

### 字体角色

| 角色 | 用途 | 现有来源 |
|---|---|---|
| Display Serif | 作品名、章节名、艺术家宣言 | 项目已有衬线字体或系统衬线回退 |
| Mono / Technical | Token、地址、交易、状态、键位 | 项目已有等宽字体 |
| Sans | 中文正文、按钮、导航、辅助说明 | 项目已有无衬线字体 |

### 📦 范围

- `src/styles/p11-tokens.css`
- `app/layout.tsx`（仅当现有字体注册需要补角色）

### 实施要求

1. 建立 display、title、body、caption、mono 五级文本样式。
2. 中文正文必须有可靠回退，不用英文衬线强撑汉字。
3. 地址和哈希使用等宽字体，但允许断行或中段省略。
4. 最小正文 14 px；核心按钮与表单文字不低于 16 px。

### 验收

- 作品名和链上数据一眼能区分层级。
- 320–375 px 下哈希不制造横向滚动。
- 浏览器字体加载失败时仍可读。
- `bash scripts/verify.sh` 通过。

## A3｜共用页面骨架

### 📦 范围

- `src/components/p11/PageShell.tsx`
- `src/components/p11/PageHeader.tsx`
- `src/components/p11/BackLink.tsx`
- `src/components/p11/StatusPanel.tsx`
- `src/components/p11/ChainValue.tsx`
- `src/styles/p11-shell.css`

> `src/components/p11/` 单层最多 8 个文件；继续增长前先拆子目录。

### 组件职责

- `PageShell`：统一内容宽度、顶部和底部安全区，不接管业务数据。
- `PageHeader`：页面眉题和一句辅助说明，不内置某条路由文案。
- `BackLink`：返回池塘的清晰文本入口，支持键盘焦点。
- `StatusPanel`：加载、空、错误、处理中共用结构，不吞掉真实错误。
- `ChainValue`：完整值、可读短值、复制行为与外链语义统一。

### 禁止

- 不建立万能 `Card`、`Button` 组件库。
- 不把业务查询、钱包状态或播放器状态放进视觉组件。
- 不用 `div` 模拟原生按钮或链接。

### 验收

- 组件 API 只表达视觉职责。
- 键盘可见焦点，点击目标不小于 44 × 44 px。
- 组件文件均不超过规范硬线。
- `bash scripts/verify.sh` 通过。

## A4｜移动端与动效基线

### 规则

1. 先在 375 px 定稿，再扩展到 768 和 1440 px。
2. 页面不横向滚动；长哈希使用断行、复制或中段省略。
3. 固定底栏必须尊重 `env(safe-area-inset-bottom)`。
4. hover 只是增强，所有操作在触屏和键盘下都完整。
5. `prefers-reduced-motion` 下保留状态变化，缩短或取消空间运动。
6. 页面切换不使用全屏长淡入，不延迟首个可操作控件。

### 验收矩阵

| 项目 | 375 | 768 | 1440 |
|---|---:|---:|---:|
| 横向滚动 | 0 | 0 | 0 |
| 键盘焦点丢失 | 0 | 0 | 0 |
| 文字遮挡 | 0 | 0 | 0 |
| 底部安全区冲突 | 0 | 0 | 0 |

### Track A 完成条件

- 设计令牌、排版角色、五个小组件和响应式规则全部落地。
- 不改变任何业务行为。
- 完整验证通过，`STATUS.md` 指向 Track B。
- 用户通过基础视觉门后再进入 `/score/[id]`。
