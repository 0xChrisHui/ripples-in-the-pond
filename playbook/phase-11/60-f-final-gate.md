## F1｜自动验证

### 必跑

```bash
bash scripts/verify.sh
```

按脚本实际包含项记录 TypeScript、ESLint、硬线、危险扫描、生产构建和 Forge 结果，不手写虚假分项。

### 定向检查

- `/score` 数据层测试：数据库主路径、tokenURI 降级、元数据 URL 白名单、作者/持有人语义。
- iframe 消息测试：忽略非当前 iframe 来源，v1 状态正确处理。
- 全局音频测试：进入 Score 暂停，离开不自行恢复。
- 生命周期映射测试：真实后端阶段均有唯一用户文案。
- OG/海报路由返回正确媒体类型。

### 通过标准

- 不允许以“与 P11 无关”为理由忽略新出现的失败。
- 外部服务瞬时故障必须保存原错误并停下，用户再次指令后才能重跑。
- 不通过降级 lint、跳过类型或删除测试来获得绿色。

## F3｜播放与永久性专项

### 历史永久性

1. 记录两枚不同历史 Token 的 metadata URL 与 `animation_url`。
2. 证明页面 iframe `src` 与元数据逐字一致。
3. 证明当前环境 Decoder 地址变化不会覆盖历史地址。
4. 在数据库不可用路径再验证一次相同结论。

### 音频状态机

```text
首页/档案播放
      ↓ 进入 /score
全局音源暂停且底栏隐藏
      ↓ Decoder 播放
只听到 Decoder
      ↓ 离开 /score
Decoder 结束；旧音源不自动恢复
```

### iframe 操作

- ready 前按钮不谎称已播放。
- play/pause/toggle 状态与声音一致。
- `ended` 后可再次播放。
- 错误后有重试和永久页出口。
- 来自其他 frame/window 的伪消息不能改变状态。
- 移动端没有内外双滚动造成的内容陷阱。

## F4｜可访问性与交互

### 键盘

- 从页面顶部 Tab 到所有动作，焦点顺序与视觉顺序一致。
- iframe 前后都有可理解的焦点位置。
- 登录弹窗有正确焦点约束与恢复。
- 复制、分享、播放器不依赖鼠标。

### 读屏与语义

- 每页只有一个主标题。
- 链上短值的可访问名称包含完整语义，不把省略字符串当完整值朗读。
- 状态变化有文本和 live region，不只靠颜色或动画。
- 装饰波纹与纹理不进入读屏树。

### 视觉舒适度

- 正文对比度 ≥ 4.5:1；大字、边界和焦点 ≥ 3:1。
- 200% 缩放仍能完成所有操作。
- reduced-motion 下没有大位移动画，信息和生命周期仍更新。
- 触屏目标至少 44 × 44 px。

## F5｜性能与韧性

### 检查

- 首页首屏不因 P11 加载 Decoder、档案或艺术家代码。
- `/score` 只载入当前一枚 Decoder，不预载多枚音频。
- iframe 加载不阻断原生身份和凭证首屏。
- 图片有明确尺寸，字体失败有回退，海报生成不拖慢页面 HTML。
- 断开数据库后已铸造 Token 仍能从链上 + Arweave 打开。
- Arweave 慢或失败时页面仍保留 Token、合约和返回入口。
- 没有因视觉重设计新增第三方依赖或远程追踪脚本。

### 建议证据

- 生产构建路由大小对比。
- 三档视口截图。
- 数据库降级录像或连续截图。
- 两枚历史 Token 的 metadata/iframe 对照。
- 键盘路径与 reduced-motion 检查记录。
