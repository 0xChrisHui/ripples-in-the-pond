# Phase 11 v3 — 全站「作品水塘」UI 再设计

> **启动日期**：2026-09-01
> **v3 拍板**：2026-09-01
> **视觉哲学**：Immersive Generative Pond × Archival Provenance
> **真实基线**：`/score-lab/1` 与 `reviews/evidence/p11-score-single-sphere/`

---

## 1. 三句话概念简报

1. `/score/[id]` 不是缩小版首页，也不是唱片册，而是一件作品自己的水塘：同一枚作品锚点在静态唱片与播放日食之间切换。
2. 375px 是“可播放的作品封面”，只保留明确的点击开始与声音驱动演出；具备精细指针的桌面才增加探索性的鼠标互动。
3. 分享与永久凭证不是附属信息；即使 WebGL、音频或数据库降级，作品身份、完整来源和分享仍然可见、可复制、可核验。

## 2. 已冻结决策

### D1 — 同源水塘，单一作品锚点

- `/score/[id]` 复用生产 `pond-gl-test3` 的同一套水面、花瓣、微光、日食与性能降级能力，不临摹、不嵌入第三套视觉引擎。
- 首页输入 35 个节点，Score 输入 1 个作品节点；两页共享渲染能力，但路由状态必须隔离。
- `idle` 不显示球体，只显示使用该 Token 永久封面的静态唱片。
- 用户点击唱片或“开始播放”后，唱片在约 450ms 内转为日食；暂停、结束或播放失败时回到唱片锚点。

### D2 — 永久输入，当前站内重演

- 已铸作品只从该 NFT metadata 的 `animation_url` 解析 `events/base/sounds` 三个永久资源，不用当前环境配置替换历史输入。
- 站内 Web Audio 驱动底曲、音效、进度与 P9 视觉事件；永久 Decoder 继续服务 NFT、站外入口与灾备。
- P9 严格走 G5 → G6 → G7：`V×6` 代表家族先通过连续演奏与恢复验收，再扩展其余真实 Events；不一次性制造 35 套新动画。

### D3 — 桌面可探索，手机可播放

- 交互能力以 `(hover: hover) and (pointer: fine)` 为主判据，不只按像素宽度猜设备。
- 精细指针桌面保留水面跟随、悬停、视差、鼠标扰动与已批准的点击反馈。
- 手机/粗指针设备关闭悬停、跟手视差、持续触摸追踪和额外指针粒子；只保留点击开始、播放控制、水波/花瓣环境与声音驱动动画。
- `prefers-reduced-motion` 是独立护栏：进一步降低花瓣、位移、转场和水面负载，但不隐藏播放状态。

### D4 — 分享与凭证属于主任务

- 首屏始终有可见分享入口，不藏入页尾或二级菜单；至少提供系统/复制链接的直接动作。
- 下方凭证账本收纳完整合约、Token、当前持有人、创作者、mint tx、setURI tx、tokenURI、metadata、events/base/sounds 与永久 Decoder。
- 视觉上可中段省略哈希，但复制值和 accessible name 必须保留完整原文；`ownerOf` 不冒充创作者。

### D5 — 视觉与工程护栏

- 暗色单主题是当前作品条件；P11 只扩展现有 `--pond-*`，不替换 P8 运行时变量。
- UI 强调从冷淡蓝改为暖墨黑、骨白、氧化黄铜与低饱和植被色；淡蓝只允许存在于真实水体光色，不承担主要操作语义。
- 一页最多一棵 R3F Canvas 与现有花瓣 Canvas；不新增渲染依赖、后处理库或第二个播放内核。
- Score 挂载时停止并隐藏全局播放器；卸载时清理 P9、pointer、水面和 AudioContext 路由会话，不能污染首页。
- 无 WebGL、context lost、低性能或资源失败时，唱片、身份、分享、凭证与永久 Decoder 出口仍可使用。

### D6 — 架构同步门

- 当前 `docs/ARCHITECTURE.md` 仍写“原生 React/CSS + Web Audio、不加载 Score WebGL”的 v2 结论，与本 playbook v3 冲突。
- 本次只按用户指令更新 playbook，不暗改架构文件；进入生产 `/score` 施工前，必须单独取得“更新 ARCHITECTURE”的明确授权并完成同步。

## 4. Score 体验结构

```text
作品水塘 Hero
├─ 常驻：返回 / Token 摘要 / 分享
├─ idle/loading/paused/ended：静态唱片
└─ playing：同一锚点切换为日食 + 永久 Events 驱动 P9

向下滚动
├─ 作品注脚与演奏摘要
└─ 永久凭证账本（高不透明阅读表面）
```

- Hero 负责“感受这件作品”，账本负责“证明这件作品”。
- 账本进入阅读区时降低指针扰动和环境活跃度，不用滚动位置控制播放。
- 唱片不是弹窗、卡片或唱片盒；它是播放前后的稳定作品身份。

## 5. 数据与永久性真值

```text
未完成 UUID
└─ 数据库：路由、创作者、底曲、事件数与真实队列阶段

已完成 Token
├─ 数据库：快速定位、创作者与队列凭证
├─ NFT metadata：永久钉住 events/base/sounds
├─ 站内 Web Audio + P9：当前站内的视听重演
└─ 永久 Decoder：NFT 自包含播放器、站外入口与灾备
```

- 数字 Token 在数据库不可用时仍从 OP Mainnet `tokenURI → Arweave metadata` 重建身份、播放 manifest 与凭证。
- 站内解释可以演进，永久输入不能被当前数据库或环境变量偷换。
- 页面不执行 metadata 中的第三方脚本；永久 Decoder 只作为用户主动打开的新页面。

## 7. 全局工程规则

1. 先设计 375px，再以 `min-width` 扩展布局；指针能力另用 interaction media query。
2. 触控目标 ≥44×44px；移动正文 ≥16px；正文行长保持 45–75 字符。
3. 设计值进入语义 CSS variables；组件不重复硬编码颜色、间距和时长。
4. 不为 P11 新增依赖；需要新依赖立即越界停。
5. loading、empty、error、processing、degraded 都有真实文案，禁止白屏和产品 mock。
6. 动效支持 reduced-motion；移动降级与 reduced-motion 不混为同一条件。
7. 每步执行 `bash scripts/verify.sh`；失败立即停，不改相邻文件救火。
8. 未经用户明确说 `commit / 发布`，不提交、不推送、不部署。
