# Track E — 全局表面整合

> **目标**：把首页入口、登录、全局播放器、系统状态与分享图统一到 P11；本 Track 只改跨页面体验，不重做首页 P9 演奏系统。

---

## E1｜首页导航与入口

### 📦 范围

- 首页现有导航/浮层组件
- `app/page.tsx`（仅入口编排）
- 对应局部样式

### 要做什么

1. 在不遮挡夜塘演奏的前提下，清晰提供“我的音乐”“108 计划”入口。
2. 产品名继续写 `Ripples in the Pond`；仓库内部名不进入 UI。
3. 当前页面、登录状态和键盘焦点有可见反馈。
4. 手机端入口可以展开，但必须原生可操作、可关闭、可返回演奏。

### 禁止

- 不改 P9 的 33 键音画、调参存档或事件映射。
- 不在首屏放传统大导航栏压缩演奏画布。
- 不依赖 hover 暴露唯一入口。

### 验收

- 375 px 下入口不会压住核心演奏和状态反馈。
- 从三条主要路由均能回到池塘。
- 键盘导航次序与视觉次序一致。
- `bash scripts/verify.sh` 通过。

---

## E2｜登录弹窗

### 📦 范围

- 现有 `LoginModal` 及其样式
- 仅为可访问性需要时调整触发器

### 视觉与行为

- 像一张浮在夜塘上的身份纸页，保留 P11 墨黑、暖白、雾蓝和金色。
- 说明“登录用于找回你的音乐档案”，不使用泛化营销文案。
- 钱包和其他既有登录方式按真实能力显示，不新增入口。
- 打开后焦点进入弹窗；Tab 被约束；Escape 与关闭按钮有效；关闭后焦点回到触发器。
- 登录中、失败、成功均有文本状态；错误不可只显示红边。

### 禁止

- 不改认证 provider、session、回调 URL 或钱包签名协议。
- 不为视觉效果自动弹窗。
- 不保存或打印地址以外的敏感认证信息。

### 验收

- 鼠标、键盘、触屏可完整完成或退出登录。
- 320–375 px 软键盘出现时主要按钮仍可达。
- 登录错误不会关闭弹窗或丢失上下文。
- `bash scripts/verify.sh` 通过。

## E3｜全局播放器

### 📦 范围

- `src/components/player/BottomPlayer.tsx`
- `src/components/player/PlayerProvider.tsx`
- 对应播放器样式

### 设计

- 播放器像窄唱片标签：作品名、播放/暂停、当前时间与进度。
- 桌面靠底但不横跨成厚工具栏；手机尊重安全区。
- 进度条触控目标足够大，视觉线可以保持细。
- 标题很长时省略，但可访问名称保留完整标题。

### 路由互斥

| 场景 | 全局播放器 |
|---|---|
| `/` 播放底曲或档案录音 | 按既有逻辑显示 |
| `/me` 试听录音 | 显示 |
| `/score/[id]` Decoder 页面 | 隐藏并暂停旧音源 |
| 登录弹窗打开 | 保持状态，不盖住弹窗动作 |

### 验收

- 任意时刻只有一个可听音源。
- `/score` 往返不自动恢复未授权声音。
- 375 px 下不遮住页面最后一个按钮。
- reduced-motion 不影响进度准确性。
- `bash scripts/verify.sh` 通过。

## E4｜加载、空、错误与 404

### 📦 范围

- 已有 `loading.tsx` / `error.tsx` / `not-found.tsx`
- Track A 的 `StatusPanel`
- `app/layout.tsx` 的语言与元数据（若审计确认不正确）

### 状态语言

- 加载：纸面轮廓和稳定排版，不无限旋转大图标。
- 空：说明为什么为空，以及唯一下一步。
- 可恢复错误：保留页面身份，提供重试。
- 不存在：明确“这张唱片不存在”，返回池塘。
- 降级：蓝灰提示“正从链上与 Arweave 读取”，不是失败红色。

### 全局一致性

- 同一种状态只用一种图标、标题格式和动作顺序。
- 所有页面使用中文可读文案；技术名词在必要处保留英文。
- 根文档 `lang` 与主要内容语言一致。
- 错误 UI 不泄露堆栈、查询、内部 URL 或密钥。

### 验收

- 断网、数据库故障、404、无认证、空数据分别有真实测试证据。
- 状态改变通过 `aria-live` 或等价方式可被读屏感知。
- 骨架加载不会出现显著布局跳动。
- `bash scripts/verify.sh` 通过。

## E5｜OG 图、海报与分享闭环

### 📦 范围

- `app/score/[id]/opengraph-image.tsx`
- `app/score/[id]/poster/route.tsx`
- 分享组件与站点 metadata

### 统一构图

- 产品名、`Ripples #NNN`、暖白纸面大字、雾蓝技术信息、单个金色编号。
- 海报可以展示创作者短地址和 Token ID；不展示数据库 UUID。
- OG 图在缩略图尺寸下先读作品名，再读产品名。
- 分享文案使用 canonical `/score/<tokenId>`；处理中 UUID 不对外当永久链接宣传。

### 准确性

- 合约地址、交易哈希、Token ID 仍按 Track B 术语区分。
- 无创作者真值时不把当前持有人写入“Created by”。
- 图片生成失败不阻断作品页；下载动作给出明确错误。

### Track E 完成条件

- 首页入口、登录、播放器、系统状态、OG/海报属于同一视觉系统。
- P9 演奏行为与认证核心未被改写。
- 跨路由音频互斥、移动安全区和键盘行为通过。
- 更新 `STATUS.md` 后停下，等待进入最终 Gate。
